# E-commerce Grocery Shop (Kabul Fresh Mart)

Sayeda Taiba Agha (Product Owner)

## Product Backlog

This product backlog has 5 epics: **Registration, Catalog/Search, Cart Management, Payment/Checkout, and Admin Panel.** For each epic, the user stories are developed as follows:

| ID | User Story | Acceptance Criteria | Priority | Sprint | Responsibility |
|---|---|---|---|---|---|
| **US-01** | As a new customer, I would like to register my account by entering some basic details, including my name, email ID, and password, so that I can access the various services offered to registered users. | Only after providing correct details such as name, email, and password are users able to create an account. | **High** | Sprint 1 | Frontend + Backend |
| **US-02** | As a registered user, I would like to sign in to my account by using my account details so that I can safely access my account and perform various activities, including shopping and ordering. | The platform accepts logins from authorized users who have valid login details while rejecting any invalid sign-ins. | **High** | Sprint 1 | Frontend + Backend |
| **US-03** | As a signed-in user, I would like to log out of my account after finishing my activity on the account so that I can keep my account safe. | A proper logout option to end the active user session. | **High** | Sprint 1 | Frontend + Backend |
| **US-04** | As a customer, I need to browse the product catalog of the store in order to get a list of the grocery products available at the moment along with useful information like product name, price, picture, and availability. | A well-displayed catalog with product details such as name, price, picture, and stock availability. | **High** | Sprint 1 | Frontend + Backend |
| **US-05** | In my capacity as a client, I would like to place a product in my shopping cart, which will enable me to store it together with other products that I will buy. | Add cart option for each product by clicking, which allows the user to add the product to their cart. | **High** | Sprint 2 | Frontend + Backend |
| **US-06** | In my capacity as a client, I would like to see all the products present in my shopping cart so as to ensure that I choose products that I require to purchase. | Cart page that shows all the added products by the user. | **High** | Sprint 2 | Frontend + Backend |
| **US-07** | In my capacity as a client, I would like to modify the quantity of a particular product present in my shopping cart so as to ensure that there is an accurate number of products present. | Quantity controller that helps add or reduce the number of the product. | **High** | Sprint 2 | Frontend + Backend |
| **US-08** | In my capacity as a client, I would like to delete one product in my shopping cart so as to make a correction in case I decide to purchase a different product. | Remove option for each product. | **High** | Sprint 2 | Frontend + Backend |
| **US-09** | In my capacity as a client, I would like to empty my shopping cart so as to be able to initiate the whole process once more. | Clear all option that clears the whole cart at once. | **High** | Sprint 2 | Frontend + Backend |
| **US-10** | In my capacity as a client, I would like to see the total price of the products in my shopping cart. | A total price section that gives the summary of the product purchase with correct price calculation. | **High** | Sprint 2 | Frontend + Backend |
| **US-11** | As a user, I want to fill in my contact details at checkout in order to know how to contact me in case something related to my order needs to be communicated. | Users shouldn’t be able to move forward with the checkout process without completing the contact detail section properly. | **High** | Sprint 3 | Frontend + Backend |
| **US-12** | As a user, I want to fill in the delivery/shipping details of my order so that the groceries can be delivered to the right destination. | Users shouldn’t be able to move forward with the checkout process without completing the shipping information section properly. | **High** | Sprint 3 | Frontend + Backend |
| **US-13** | As a user, I want to be able to choose from the different available delivery options in order to pick one that best suits my order. | The user should be able to see acceptable delivery options and choose only one option. | **High** | Sprint 3 | Frontend |
| **US-14** | As a user, I want to provide the necessary payment details at the checkout stage in order to pay for my purchase. | Only process when valid payment information is provided. | **High** | Sprint 3 | Frontend + Backend |
| **US-15** | As a user, I want to review my selection of products, quantity, delivery, payment information, and order total before ordering so that I can spot any mistake I have made during the checkout process. | User should be able to see order summary with all the product details before actually placing the order. | **High** | Sprint 3 | Frontend + Backend |
| **US-16** | As a user, I want to order after reviewing my checkout information so that my order gets delivered by the store. | Place order option should only work when all the required sections are completed properly. | **High** | Sprint 3 | Backend |
| **US-17** | As a user, I want to be informed in case my order has been successfully placed so that I can be assured that my order has been received. | Order confirmation after the order is placed. | **High** | Sprint 3 | Frontend + Backend |
| **US-18** | As an authorized administrator, I would like to have an administrator account because I need to perform the management operations that regular customers cannot do. | Admin registration page that accepts only valid details. | **High** | Sprint 4 | Backend |
| **US-19** | As an administrator, I would like to securely log in to the admin panel because this allows only authorized users to perform product, inventory, order, and customer management operations. | Admin login page where only authorized admins can sign in. | **High** | Sprint 4 | Frontend + Backend |
| **US-20** | As an administrator, I would like to log out from the admin panel once I have finished performing the necessary actions, in order to protect access to administrative operations. | Log out option for the admin panel to end the active session on the platform for admins. | **High** | Sprint 4 | Frontend + Backend |
| **US-21** | As an administrator, I would like to add, edit, or delete products, in order to make sure the database is filled with current information about the products. | Product management section where an admin can perform certain functions such as adding, editing, and deleting a product. | **High** | Sprint 4 | Frontend + Backend |
| **US-22** | As an administrator, I would like to manage the available quantity or the availability of the products, in order to inform the customer whether the chosen grocery item is available for purchase or not. | Inventory management section to monitor and update the stock. | **High** | Sprint 4 | Frontend + Backend |
| **US-23** | As a customer, I need to open a chosen product and have a closer look at it so that I can be sure what I buy and decide whether I want to put it into the shopping cart. | By clicking the specific product card, the user should be able to see clear and detailed information about that specific product. | **Medium** | Sprint 1 | Frontend |
| **US-24** | As a customer, I need to find a product by entering its name or some keyword so that I can find a required grocery product without viewing the whole product catalog. | Search section that helps find the needed product. | **Medium** | Sprint 1 | Frontend + Backend |
| **US-25** | As a customer, I need to apply filters to the product catalog based on useful criteria like product category or availability so that I can decrease the number of products shown and concentrate only on useful items. | Filter option that filters the product using available filter options. | **Medium** | Sprint 1 | Frontend + Backend |
| **US-26** | As a customer, I need to sort the products shown based on some useful criteria like price so that I can compare and browse products easily. | Sort option to reorder the product list by alphabetical order or price. | **Medium** | Sprint 1 | Frontend |
| **US-27** | As a registered user, I want to be able to see my previous orders in platform so that I can keep a record of my previous orders. | View order history. | **Medium** | Sprint 3 | Frontend + Backend |
| **US-28** | As an administrator, I would like to review and manage the customer orders and their order information/status, in order to manage orders effectively. | Customer order view and management section for admin. | **Medium** | Sprint 4 | Frontend + Backend |
| **US-29** | As an administrator, I would like to review and manage customer information if needed, in order to manage customers' accounts. | Customer account section so admin can see their customers' information. | **Medium** | Sprint 4 | Frontend + Backend |
