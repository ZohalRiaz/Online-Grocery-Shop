## 4. User Abilities After Sprint 2 Has Been Completed

- Users can add products in stock to their cart.
- Users can see all the products that the added to the cart in the cart page.
- Users can see a total summary section in the cart page.
- Users cannot add products out of stock to their cart.
- Customers can manage product quantities using quantity controller (increase & decrease) in product details.
- Customers can manage product quantities using quantity controller (increase & decrease) in cart page.
- Users can see a pop up message when the product is added to the cart.
- Users can put a valid amount for the product quantity.
- Users can see a pop-up message if they put invalid number in quantity controller.
- User can remove an individual product from the cart.
- Users can clear the whole cart.
